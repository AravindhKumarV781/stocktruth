# StockTruth

Governed multi-agent investigation of stock mismatches (retail), built for the Azure portal.

- `RUNBOOK.md`: follow Steps 1 to 13 in Azure Cloud Shell, then Phase 2 (CCTV). Nothing is installed on your computer.
- `RUN_ORDER.md`: one table showing which script to run, when, where, and what it produces.
- `docs/PRODUCTION_PATH.md`: judging-criteria map, production path, repeatability.
- `docs/PHASE2_CCTV.md`: CCTV-to-billing approach and code map.
